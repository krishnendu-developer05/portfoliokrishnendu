## Architecture & Interactive Components

- **GooeyNav (ApexUI / React Bits Spec)**: Fluid navigation bar with physics-driven pill indicator and ambient canvas particle dynamics.
- **3D Holographic Profile Card**: Holographic sheen layer (`holo=0.8`), dynamic glare reflection, and responsive unclipped portrait rendering across mobile and desktop.
- **Compact Project Accordions**: Collapsible technical project dossiers featuring live prototype embeds and system breakdown links:
  - **RapidCare**: Real-time emergency healthcare dispatch and telemetry ecosystem.
  - **MuleShield**: Graph-based financial forensic anti-money-laundering engine.
  - **PujaGhar**: Verified traditional ritual services directory and marketplace.
  - **StockRiskAgent**: Autonomous TypeScript agentic market risk intelligence system.
- **Roles & Impact (AnimatedList Spec)**: Interactive, dark-themed milestone list (`theme="dark"`, `animation="pop"`, and `onItemSelect`) detailing PR leadership and outreach engagements.
- **Verified Engineering Stack (BounceCards Spec)**: 4-deck interactive card stack with hover spread, bounciness physics, and mobile tap inspection.
- **SpecularButton**: Native physics button (`size="lg"`, `radius=39`, ambient glow, mouse proximity tracking) for the contact dispatch pipeline.
- **System Cockpit & Case Study Modal**: 13-point architectural breakdown, C++ dispatch telemetry, and algorithmic walkthrough modal.
