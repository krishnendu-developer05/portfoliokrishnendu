# portfoliokrishnendu — SIGNAL IN THE NOISE

Portfolio of **Krishnendu Roy** — full-stack web developer, CSE student at Academy of Technology, learning agentic AI and spec-driven development.

**Live (after GitHub Pages is enabled):** https://krishnendu-developer05.github.io/portfoliokrishnendu/

## Stack
- Dependency-free static site: HTML + CSS + vanilla JS
- Motion via CDN: GSAP + ScrollTrigger, Lenis smooth scroll
- One canvas scene (CH 00): particles assemble from noise into a lattice — "noise → signal"
- Signal terminal: press `/` (commands: origin, mind, build, process, human, next, negative, reset)

## Design system
- Void Black `#08090B` · Graphite `#18191D` · Warm White `#F1F0EC` · Metallic Silver `#BFC2C8`
- Signal Lavender `#B7A8FF` (AI/intelligence moments) · Signal Orange `#F28A55` (one accent per chapter)
- Space Grotesk display · General Sans editorial · Inter body · IBM Plex Mono metadata
- No logo — the name exists only as editorial text
