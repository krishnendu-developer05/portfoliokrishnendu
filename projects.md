# Projects

## RapidCare — LIVE (features in progress)
Emergency response platform streamlining ambulance booking and real-time patient tracking; synchronizes patients, drivers, and hospitals.
- Shipped: OTP-verified booking with automated driver assignment; live GPS tracking and ETA (Leaflet.js + OpenStreetMap); hospital directory with live bed availability; patient dashboard; driver portal; hospital registration; analytics dashboard; insurance claim interface.
- In progress: WebSocket live chat; Gemini-powered AI triage.
- Planned: multi-language UI for rural accessibility; IoT vitals monitoring; predictive demand analytics.
- Live (functional): https://rapidcare-4gzf.onrender.com/choose_User/
- UI revamp (under work): https://rapidcare-sih-n-2b76.vercel.app/
- Code: https://github.com/krishnendu-developer05/RAPIDCARE_SIH

## MuleShield — PROTOTYPE (synthetic data)
Hackathon prototype detecting suspicious money transfers via graph-based analysis of account relationships and transaction patterns; investigator-oriented interface; risk-gated payment workflow concept.
- Transparency: demo uses illustrative data; no real bank/government integration; documented backend/ML/graph/streaming technologies describe the intended architecture, not a completed stack. Founder/project lead/product concept; AI-assisted implementation.
- Live: https://muleshield-sooty.vercel.app
- Code: https://github.com/krishnendu-developer05/MULESHILD
